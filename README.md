# AI기본법 컴플라이언스 체커 (RAG)

법무팀 없는 AI 기업이 기획 단계에서 **자사 서비스의 법적 의무를 근거 조문과 함께** 확인하는 RAG 토이 프로젝트.

Baseline 포함 6개 Pipeline을 동일 질문셋으로 측정·비교하고, 효과 없는 개선은 근거를 기록해 폐기.

| Pipeline | Recall@4 | MRR | 판단 |
|---|---|---|---|
| 1. Baseline (글자수 Chunk 200 + Similarity) | 0.611 | 0.639 | 조문 중간 절단 |
| 2. + 조 단위 Chunk | 0.556 ↓ | 0.444 ↓ | **역효과 — 단독 적용 폐기** |
| 3. + ParentDocument | 0.611 | 0.676 | 작은 조각 검색 + 조 전체 반환으로 회복 |
| 4. + Hybrid (BM25) | 0.722 | 0.704 | Recall 기여 최대 |
| 5. + Rewrite·Route | 0.611 | 0.778 | **Rewrite는 트레이드오프 — 최종 제외** |
| **6. Final (Hybrid + Route)** | **0.722** | **0.778** | 채택 |

- Baseline 대비 **Recall@4 +18% / MRR +22%**
- 평가 조건·질문별 결과 → [results/evaluation.md](results/evaluation.md)
- 설계 근거 → [results/design.md](results/design.md)

## 문제 정의

- AI기본법은 추상적 표현으로 작성되고, 법률·시행령·가이드라인에 분산되며, 조문 간 상호 참조
- 질문과 조문의 언어가 불일치 — 사용자는 사업 언어("채용 솔루션", "벌금"), 법은 법률 언어("채용 판단에 활용되는 고영향 인공지능", "과태료")
- 목표 3가지
  - 관련 조문을 찾아 인용하며 답변
  - 근거가 없으면 답하지 않음
  - 해당 여부는 단정하지 않고 "가능성"으로만 표현

## 측정에서 나온 판단 4가지

**1. "구조를 살리면 좋아진다"는 가정이 틀림**

- 조문 경계 Chunk 적용 시 Recall@4 0.611 → **0.556 하락**
- 원인 — 긴 조문을 통째로 임베딩하면 의미 희석
- 조치 — ParentDocument(작은 조각으로 검색 → 조 전체 반환)로 교체, MRR 0.444 → 0.676 회복

**2. 지표가 오른 개선을 제외**

- Rewrite 적용 시 MRR 최고치 0.778, 그러나 Recall 0.722 → 0.611 하락
- 원인 — 원 질의와 재작성 질의가 Top-4를 분할 점유
- 판단 — Top-K 고정 조건에서는 손해. Rewrite 제외, 효과가 분명한 Route("제N조" 직접 조회)만 유지
- 결과 — "제34조는 무슨 내용이야?" 정답 조항 4위 → **1위**

**3. 남은 실패를 원인까지 추적**

- "고영향 인공지능이 정확히 뭐야?" — 6개 Pipeline 전부 실패
- 디버깅 결과 — FAQ의 질문 문장이 거리 0.50으로 최근접, 정답인 정의 조항은 0.80
- 해석 — 검색 실패가 아니라 **질문↔조문 문체 차이**. 질문형끼리 가깝고 선언문(`"…"이란 …을 말한다`)은 멂
- 다음 개선 후보 — HyDE

**4. 구현 중 발견한 버그 2건**

- Rewrite 결과를 순위 교차로 병합 → 하위 질의 3개 시 각 질의의 1위만 Top-4 진입 → **RRF 병합으로 변경**
- 중복 제거가 마지막 등장 위치 기준 정렬 → Route로 1위에 올린 조문이 후순위로 밀림 → **첫 등장 순서 유지로 수정**, MRR 0.704 → 0.778

## 생성 결과 확인

| 질문 | 결과 |
|---|---|
| 이력서 자동 선별 채용 솔루션도 규제 대상? | 시행령 제2조 인용, "해당할 가능성이 높습니다" (개선 전에는 무관한 제35조 인용) |
| 생성형 챗봇 고지 의무 + 과태료 | 고지 의무는 제31조로 정확, 과태료 제43조 누락 — Retrieval 실패가 답변 누락으로 연결 |
| 미국 AI 규제와 비교하면? | "제공된 문서에서 확인할 수 없습니다" |

- 전 답변에 법률 자문이 아니라는 면책 문구 부착

## 구조

![Pipeline](results/pipeline.png)

| 항목 | 값 |
|---|---|
| Embedding / LLM | `text-embedding-3-small` / `gpt-4o-mini` (temperature=0) |
| Vector Store | FAISS |
| Retriever | ParentDocument + BM25 Hybrid + Route |
| Top-K | 4 (전 Pipeline 동일) |
| 질문셋 | 고정 10개 (Retrieval 평가는 문서에 없는 질문 제외한 9개) |

## 한계

- **질문셋 9개** — 표본이 작아 지표 변동 큼. 20개 이상으로 확대 필요
- **복합 질문의 두 번째 주제 누락** — "고지 의무 + 과태료"에서 제43조 누락. 하위 질의별 Top-k 할당 또는 Reranker 필요
- **교차참조 미확장** — 제34조가 제33조를 참조해도 자동으로 따라가지 못함
- **문체 차이** — 위 3번 참조. HyDE 적용 예정
