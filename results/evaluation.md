## 3. 단계별 해석

1. **조 단위 Chunk는 단독으로는 역효과였다 (0.611 → 0.556).** 긴 조문을 통째로 임베딩하면 의미가 희석된다. "구조를 살리면 무조건 좋아진다"는 가정이 틀렸음을 확인했다.
2. **ParentDocument로 회복했다.** 작은 조각으로 검색하고 조 전체를 반환하니 MRR이 0.444 → 0.676으로 올랐다.
3. **Hybrid가 Recall을 가장 많이 끌어올렸다 (→ 0.722).** "결과물 표시" → 령 제3조, "과태료/계도" → 령 제7조처럼 법률 용어가 그대로 겹치는 조문을 BM25가 보완했다.
4. **Rewrite는 트레이드오프였다.**
   - 첫 시도: LLM이 단일 질문까지 "저작권", "활용 사례" 같은 없는 주제로 쪼개 노이즈가 생겼다. 프롬프트를 "명시적으로 여러 주제를 물을 때만 분해"로 고쳤다.
   - 수정 후: MRR은 최고(0.778)였지만, 원래 질의와 바꾼 질의가 Top-4를 나눠 가지면서 Recall이 0.611로 떨어졌다.
   - 결론: Top-4 제약에서는 Rewrite를 빼고, 효과가 확실한 **Route**("제N조" 직접 조회)만 남겼다. 그 결과 제34조가 4위 → 1위가 됐다.
5. **실패가 남은 질문:** "고영향 인공지능이 뭐야?"는 모든 Pipeline에서 실패했다.
   - 디버깅해 보니 FAQ의 질문 문장 "고영향 인공지능인지 애매하면…"이 가장 가까웠다(거리 0.50). 정답 조각은 0.80으로 멀었다.
   - 질문형 문장끼리 가깝고, 선언문(`"…"이란 …을 말한다`)은 멀다. 즉 **질문↔조문 문체 차이** 문제다 → 다음 개선 후보는 HyDE.

### 진행 중 발견한 구현 버그 (기록)
- Rewrite 결과를 순위 교차로 병합 → 하위 질의가 3개면 각 질의의 1위만 Top-4에 들어감 → **RRF 병합으로 변경**
- 중복 제거가 마지막 등장 위치 기준으로 정렬 → Route로 1위에 넣은 조문이 뒤로 밀림 → **첫 등장 순서 유지로 수정** (MRR 0.704 → 0.778)

## 5. 결론

- 최종 채택: **조 단위 ParentDocument + BM25 Hybrid + 조항 Route**
- Baseline 대비 Recall@4 **+18%**, MRR **+22%**, 근거 조항 인용 정확도 개선
- 남은 과제: 질문↔조문 문체 차이(HyDE), 복합 질문의 두 번째 주제 누락(하위 질의별 슬롯 또는 Reranker), 질문셋 확대(9개는 변동이 큼)
